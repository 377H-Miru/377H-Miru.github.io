I share software developed during my research for cheminformatics and data analysis.

ecfp_cli [Upcoming]

Fast and robust ECFP fingerprint generation from SMILES

  • Key Features:
    • High-speed parallel processing for large datasets.
    • Automatic detection of invalid SMILES with detailed error logging.
    • Built-in salt removal and fragment handling.
  • Use Case: Utilized for data preprocessing in the poster presentation at the 146th Annual Meeting of the Pharmaceutical Society of Japan.
  • Links: [GitHub Repository] ｜ [Latest Release (v0.1.1)]

mordred_descriptor_calculator [Upcoming]

Reproducible descriptor calculation with pi-conjugation support

  • Key Features:
    • High reproducibility via deterministic seeding and MMFF energy minimization.
    • Unique estimation of pi-conjugated system quality (Conjugation Features).
    • Batch calculation of 1,800+ Mordred descriptors.
  • Use Case: Utilized for feature extraction in the EUOS25 challenge (Fluorescence track winner).
  • Links: [GitHub Repository] ｜ [Latest Release (v0.1.1)]

Installation

After cloning the repository, install the dependencies using the following commands:

# For ecfp_cli
git clone https://github.com/377H-Miru/ecfp_cli.git
cd ecfp_cli
pip install -r requirements.txt

# For mordred_descriptor_calculator
git clone https://github.com/377H-Miru/mordred_descriptor_calculator.git
cd mordred_descriptor_calculator
pip install -r requirements.txt

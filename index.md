## 研究領域
- **副作用発現メカニズムの探求:** Kolmogorov-Arnold Networks (KAN) の解釈性を活用したToxicophore（毒性発現部位）の同定に取り組んでいます。KAN固有の課題であるスケーラビリティに対し、アーキテクチャの最適化を通じた克服を目指しています。将来的には標的タンパク質ドッキングシミュレーションを統合し、分子から受容体レベルまで多角的に医薬品の安全性を評価する基盤構築を目的としています。
- **RWD解析への展開:** 自発報告データベース（FAERS）での知見をベースとした、実臨床データ解析への拡張を検証しています。

## Research Focus
- **Investigating Adverse Event Mechanisms:** Identifying Toxicophores using KAN interpretability. My work addresses KAN's scalability trade-offs through architectural optimization, aiming to integrate receptor-level docking simulations for a multi-dimensional safety assessment framework.
- **Expansion to RWD Analysis:** Validating the application of FAERS-based findings to clinical data analysis using Japanese claims data.

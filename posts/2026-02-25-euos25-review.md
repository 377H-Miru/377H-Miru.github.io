# EUOS25 challenge（蛍光予測部門）で用いた手法

2026年2月に結果が発表された「EUOS25 challenge」（EU-OPENSCREEN と SLAS による第2回 Joint Machine Learning Challenge）で、私たちのチーム（Team microsomes）は蛍光予測部門で優勝しました。この記事では、チームで用いた特徴量と、直列スタッキングという予測の組み立て方を紹介します。

## コンテストの概要
化合物ライブラリを対象に、化合物の光学特性を予測する課題でした。次の2つの部門がありました。

1. **透過率（Transmittance）予測**
2. **蛍光（Fluorescence）予測**

## 用いた特徴量

化合物を1種類の表現だけで扱うのではなく、性質の異なる複数の特徴量を組み合わせました。

1. **量子化学計算**
   - MOPAC（6種類のハミルトニアン）と MACE-xTB を用いて計算しました。
   - DMSO 溶媒条件での HOMO-LUMO ギャップなどの値を、特徴量として加えました。
2. **記述子**
   - Mordred 記述子に、PathCounts（最大50次）を加えました。
   - π 共役に関する特徴量（Conjugation Features）を加えました。
3. **グラフニューラルネットワーク**
   - GINE-Net から得た埋め込みを特徴量として加えました。

## 直列スタッキング

蛍光の測定値は透過率（吸収）の影響を受けると考え、透過率の予測値を蛍光の予測に使う2段構成にしました。

- **1段目:** すべての特徴量から、透過率と蛍光の予測値（OOF 予測値）を作りました。
- **2段目:** 1段目で得た透過率の予測値を、蛍光を予測するモデルの入力に加えました。

## 評価
過学習の影響を抑えるため、**4×4 の入れ子交差検証（Nested Cross-Validation）** で性能を評価しました。

手法の詳細は、ChemRxiv のプレプリントにまとめています。 ｜ [Preprint (ChemRxiv)](https://chemrxiv.org/doi/full/10.26434/chemrxiv.15002662/v1)

# Methods We Used in the EUOS25 Challenge (Fluorescence Track)

[← Back to Blog List](/en/blog/)

In the EUOS25 challenge (the 2nd Joint Machine Learning Challenge by EU-OPENSCREEN and SLAS, results announced in February 2026), our team (Team microsomes) won the Fluorescence track. This post describes the features we used and how we arranged the prediction as a sequential stack.

## Challenge Overview
The task was to predict optical properties of compounds in a screening library. There were two tracks:

1. **Transmittance prediction**
2. **Fluorescence prediction**

## Features

Instead of relying on a single molecular representation, we combined several kinds of features:

1. **Quantum chemistry**
   - Calculations with MOPAC (6 Hamiltonians) and MACE-xTB.
   - Values such as the HOMO-LUMO gap under a DMSO solvent condition were added as features.
2. **Descriptors**
   - Mordred descriptors, plus PathCounts (up to order 50).
   - Features describing π-conjugation (Conjugation Features).
3. **Graph neural network**
   - Embeddings from a GINE-Net were added as features.

## Sequential Stacking

Because measured fluorescence is affected by transmittance (absorption), we used a two-stage setup in which predicted transmittance feeds the fluorescence prediction:

- **Stage 1:** out-of-fold (OOF) predictions of transmittance and fluorescence from all features.
- **Stage 2:** the stage-1 transmittance predictions were added as inputs to the fluorescence model.

## Evaluation
To limit the effect of overfitting, performance was evaluated with **4×4 nested cross-validation**.

Details are described in our ChemRxiv preprint. | [Preprint (ChemRxiv)](https://chemrxiv.org/doi/full/10.26434/chemrxiv.15002662/v1)

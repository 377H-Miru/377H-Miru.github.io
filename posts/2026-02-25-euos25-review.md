# EUOS25 challenge 優勝の技術的背景

[← ブログ一覧に戻る](/blog)

2026年2月に開催された「EUOS25 challenge（第2回 EU-OPENSCREEN / SLAS 共同機械学習チャレンジ）」の蛍光予測部門において、私たちのチーム（Team microsomes: 明治薬科大学）が優勝しました。本記事では、その際に用いた予測モデルのアーキテクチャとアプローチについて解説します。

## コンテストの概要
約10万化合物のライブラリを対象に、化合物の光学的特性（透過率および蛍光特性）を予測するタスクでした。透過率（Transmittance）予測部門と、蛍光（Fluorescence）予測部門の2つのトラックがあり、私たちは蛍光予測において最高精度を達成しました。

## 優勝の鍵：Multimodal Strategy

単一のモデルではなく、異なる視点から化合物を表現する「マルチモーダル」なアプローチを採用したことが、予測精度の底上げに繋がりました。

1. **Precision QM Strategy (量子化学アプローチ)**
   - MOPAC（6種類のハミルトニアン）と MACE-xTB ワークフローを組み合わせた精密な量子化学計算を実行。
   - DMSO溶媒環境下での熱力学物性（HOMO-LUMOギャップなど）を算出し、蛍光特性に直結する物理化学的な根拠をモデルに与えました。
2. **Massive Informatics (大規模記述子)**
   - Mordredによる1,800以上の記述子に加え、長距離相関を捉えるためのPathCounts（最大50次）を独自拡張。
   - $\pi$共役系の品質を評価するConjugation Features（GraphEnergy, BLA等）を追加し、蛍光予測に特化した特徴量空間を構築しました。
3. **GNN Feature Generation (グラフニューラルネットワーク)**
   - カスタムの GINE-Net を活用し、隠れ層のグラフエムベディング自体を特徴量として抽出・統合しました。

## Architecture: Sequential Stacking (連鎖的スタッキング)

蛍光（F）という現象は、物質が光を吸収（透過率の低下: T）した後に発生するという物理的な因果関係があります。これを機械学習モデルに組み込むため、**「Sequential Stacking」**というアーキテクチャを考案しました。

- **Tier 1:** まず、すべての特徴量から透過率（T）と蛍光（F）の初期予測値（OOF Predictions）を生成します。
- **Tier 2 (Chaining):** 
  - Stage 1 で T の予測を洗練させます。
  - Stage 2 以降で、**「元の特徴量 ＋ 改善された T の予測値」** を新たな入力として F の予測を行います。
  - このように、物理的プロセス（T $\to$ F）を模倣して予測値を連鎖的に注入することで、モデルが単なる相関ではなく、現象の依存関係を学習できるようになりました。

## 厳密な検証 (Rigorous Validation)
過学習を防ぐため、**4x4 Nested Cross-Validation**（外側4分割 / 内側4分割）を採用し、バイアスのない堅牢なモデル選択とアンサンブルの重み付けを行いました。SHAP値の解析からも、GNNのエムベディングと量子化学計算による構造記述子が共に強力に寄与していることが確認されています。

## 今後の展望
本コンペティションで培った「マルチモーダル特徴量」と「物理的因果関係を模倣したスタッキング」の技術は、他の化合物の物性・毒性予測にも応用可能です。

詳細な技術レポートとソースコードは、2026年4月に **SLAS Technology** 誌へ投稿する予定です。

# Technical Review: EUOS25 Challenge Win

[← Back to Blog List](/blog)

In February 2026, our team (Team microsomes: Meiji Pharmaceutical University) won the Fluorescence Prediction Track of the 2nd Joint Machine Learning Challenge co-organized by EU-OPENSCREEN and SLAS. This post outlines the predictive architecture and technical approaches that led to our victory.

## Challenge Overview
The objective was to predict the optical properties (transmittance and fluorescence) of a diverse library comprising approximately 100,000 compounds. 

## Key to Winning: Multimodal Strategy
Instead of relying on a single model type, we adopted a multimodal approach that represents compounds from fundamentally different perspectives:

1. **Precision QM Strategy (Quantum Chemistry)**
   - Executed precise quantum chemical calculations combining 6 MOPAC Hamiltonians and a MACE-xTB workflow.
   - Calculated thermodynamic properties (e.g., HOMO-LUMO gap) in a simulated DMSO environment, providing the model with physiochemical rationales directly related to fluorescence.
2. **Massive Informatics**
   - Utilized over 1,800 Mordred descriptors, heavily augmented with custom extensions like PathCounts (up to Order 50) for long-range correlations.
   - Incorporated Conjugation Features (GraphEnergy, BLA, etc.) to evaluate $\pi$-system quality, which is crucial for fluorescence.
3. **GNN Feature Generation**
   - Leveraged a custom GINE-Net to extract graph embeddings from hidden layers, using them as explicit features to enrich the feature space.

## Architecture: Sequential Stacking
Fluorescence (F) physically occurs after a substance absorbs light (a drop in transmittance: T). To embed this causal biophysical relationship into our machine learning model, we designed a **"Sequential Stacking"** architecture.

- **Tier 1:** Generated Out-Of-Fold (OOF) predictions for both T and F using all baseline features.
- **Tier 2 (Chaining):** 
  - Refined T predictions in earlier stages.
  - In subsequent stages, injected the **"original features + refined T predictions"** as inputs to predict F.
  - By sequentially chaining the predictions, the model learned the phenomenological dependency (T $\to$ F) rather than just statistical correlations.

## Rigorous Validation
To prevent overfitting, we employed a **4x4 Nested Cross-Validation** strategy. This ensured unbiased model selection and optimal ensemble weighting. Subsequent SHAP value analysis confirmed that both GNN embeddings and QM-based structural descriptors were the primary drivers of model accuracy.

## Future Outlook
The "Multimodal Feature" integration and "Physically-inspired Stacking" techniques developed in this competition are highly transferable to other molecular property and toxicity predictions. 

Full technical details and the source code will be submitted to the journal **SLAS Technology** in April 2026.
